## 5. Temporal Integrity & Anti-Leakage Safeguards

1. **Observation Window Bounding:** All feature columns derive exclusively from historical transactions occurring strictly prior to $t_0$ (`cutoff_timestamp`).
2. **Outcome Isolation:** Forward simulation internal variables (`consecutive_negative_days`, `prediction_horizon_days`, forward living cost shocks) are completely excluded from the dataset.
3. **Repeat-Applicant Monotonicity:** Exactly 2,000 repeat applicants have 2 applications each (4,000 total). Every repeat application is strictly separated by $\ge 30$ calendar days and has monotonic UTC timestamps ($t_1 > t_0$).

## 7. Preprocessing Pipeline (`CreditRiskPreprocessor`)

A deterministic, leakage-safe preprocessing transformer has been implemented in `src/ml/data/preprocessing.py`:

```
Raw Application DataFrame (52 cols)
  ├── 1. Insufficient Evidence Filter / Route (Null target segregated)
  ├── 2. Identity / Target Quarantine (UUIDs & target excluded from feature matrix)
  ├── 3. Missing Value Imputation (Training medians + _was_missing flags)
  ├── 4. Skewed Monetary Compression (np.log1p on currency INR columns)
  ├── 5. Leverage Ratio Winsorization (Clipping DTI & buffer to [0.0, 5.0])
  ├── 6. Robust Continuous Scaling (RobustScaler fitted strictly on Train)
  └── 7. Nominal One-Hot Encoding (OneHotEncoder with handle_unknown='ignore')
       └── ML-Ready Numerical Matrix (55 numeric features, 0 NaNs)
```

### Preprocessing Invariants
1. **Train-Only Fitting:** Scaler medians/IQRs and one-hot categories are calculated exclusively from `train_df`. Validation, test, and inference sets only call `.transform()`.
2. **Missingness Distinction:** Valid zeros (e.g. debt-free applicants with DTI = 0, zero-earning weeks = 0) are strictly preserved; only true unobserved features are imputed with training medians.
3. **Robust Unknown Category Handling:** `OneHotEncoder(handle_unknown='ignore')` maps any unobserved production category (e.g. newly introduced gig platform or loan purpose) to all-zero indicator columns without raising exceptions.
4. **Deterministic Reproducibility:** Repeated transformations on identical datasets produce bitwise-identical output arrays.
